# ASA Fashion Collection BD — Customer Website V9

Professional customer-facing ecommerce website inspired by common Bangladesh fashion/ecommerce patterns, without copying proprietary branding or content.

Included: responsive home, category navigation, flash sale, new arrivals, best selling, recommendations, recently viewed, product details with size/color/quantity, wishlist, compare, cart, checkout, COD, bKash/Nagad manual transaction fields, coupons, order tracking, reviews, FAQ, contact, customer account/login, Firebase config, PWA manifest, demo product catalog, delivery pricing (Dhaka ৳100 / outside ৳250), WhatsApp/call support.

Admin panel is intentionally excluded. Use the separate admin deployment ZIP for admin.
